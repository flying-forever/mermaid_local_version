# Mermaid 本地编辑器

双击 `启动.cmd` 即用：它起一个本地服务（`127.0.0.1:8787`）并自动打开浏览器。
把 `.md` / `.mmd` 文件拖到 `启动.cmd` 图标上，可以直接打开那个文件。

## 为什么要有它

Typora / Obsidian / VS Code 内置的 Mermaid 都是打包死的旧版本（**dagre 布局**），
子图（subgraph）一律往下堆，很快就超过一屏。这个页面直接加载 Mermaid v12：
**ELK 已是默认布局**，容器会被真正当成容器排布，横向空间用得上。

## 保存是怎么写回去的

页面**不再**用 File System Access，也不再下载文件。

保存时浏览器把纯文本 `POST` 给本地服务，由 `serve.js` 用 Node 直接写原来的路径。
所以：

- 保存就是**覆盖你打开的那个文件**，不会落到「下载」文件夹；
- 和浏览器内核无关，QQ 浏览器 / Edge / Chrome 都一样；
- 刷新页面、关掉再打开，路径都还在（`?file=` 或上次打开的文件）。

服务只允许读写 `工作流图格式_20261114/` 目录内的 `.md` / `.mmd` / `.markdown` /
`.mermaid` / `.txt`，出界一律 403；只监听本机回环地址。

## 用法

1. 双击 `启动.cmd`
2. 点「打开文件」，在目录浏览器里选一个 `.md` 或 `.mmd`
3. 左边改，右边约 0.4 秒后自动重绘
4. `Ctrl+S` 写回原文件；`Ctrl+Shift+S` 另存为

支持两种内容形态：

- `.md`：自动提取里面**所有** ```mermaid 代码块，逐块渲染（围栏没写完也能渲染）
- `.mmd` / `.txt`：整个文件就是一张图

## 工具栏

| 控件 | 说明 |
|---|---|
| 打开文件 / 保存 / 另存为 / 重载 | 保存=写回原路径；另存为=新路径；重载=丢弃未保存改动重新读盘 |
| 停止服务 | 停掉本地服务（会二次确认）。停完这个页面就不能再读写文件了 |
| 布局：ELK（推荐）/ Dagre | 切回 Dagre 可以对比旧效果 |
| 主题 | default / dark / forest / neutral |
| 每张图右上角 | 导出 SVG 或 PNG（PNG 为 2 倍分辨率、白底） |

## 语法出错时

编辑到一半语法不完整是常态，所以出错**不会**弹大框、也不会堆满页面：

- 只在该图下方显示**一行**红色提示，鼠标悬停看详情，点「详情」才展开；
- 如果这张图之前渲染成功过，**保留上一张好图**，只在旁边挂个折叠的小提示；
- 渲染失败产生的临时 DOM 会被清掉，不会累积。

## 已知限制

- **需要联网**：Mermaid 从 `cdn.jsdelivr.net` 的 `mermaid@12/+esm` 加载，首次打开要能访问；之后走浏览器缓存。CDN 卡住不影响打开和保存文件。
- 必须通过 `启动.cmd`（本地服务）打开。直接双击 `index.html` 时页面顶部会出现一条
  「未连接本地服务」的横幅，并给一个跳到本地服务的按钮（打开/保存按钮会置灰）。
- 端口 8787 被默认占用时：如果占用者就是本服务（重复双击了 `启动.cmd`），会**直接打开
  已经在跑的那个页面**然后退出，不报错；只有被其它程序占用才会提示换端口。

## 目录

```
editor/
├─ 启动.cmd      ← 入口：起服务 + 打开浏览器
├─ 停止.cmd      ← 停止已在运行的服务
├─ serve.js      ← 本地服务：静态页 + 读文件 + 写文件（node，无依赖）
├─ stop.js       ← 停止用的脚本（POST /api/shutdown）
└─ index.html    ← 全部界面与逻辑，单文件
```

## 怎么停

三种都行，效果一样：

1. 页面右上角「**停止服务**」（推荐，有二次确认）；
2. 双击 `停止.cmd`（浏览器已经关掉、找不到按钮时用）；
3. 直接关掉那个黑色命令行窗口，或 `Ctrl+C`。

**关浏览器不会停服务**，服务还在后台跑着（所以再双击 `启动.cmd` 会直接打开它）。
另外端口被占用时 `serve.js` 也会先探测是不是本服务。
